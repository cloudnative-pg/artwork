# CloudNativePG Artwork

Here you can find the official logo for **CloudNativePG**, featuring our
mascot, *Peggie*.  Peggie is a young female elephant — one of Slonik’s
daughters — who’s eager to spread the word in the Cloud Native world about how
amazing PostgreSQL is!

Since CloudNativePG joined the **CNCF**, the logo is now governed by **The
Linux Foundation** trademarks policy and is hosted in the
[CNCF artwork repository](https://github.com/cncf/artwork).
